¿Cómo se juega?
  • Toca una columna o desliza a los lados para mover la letra.
  • Desliza hacia abajo o toca dos veces para dejarla caer.
  • Forma palabras de 3 letras o más: en horizontal (izquierda a derecha) o en vertical (de arriba a abajo).
  • La ★ vale por cualquier letra. La Q siempre sale como QU.
  • Si al caer las fichas se forman más palabras, es una cadena: ×2, ×3…
  • Cada 10 palabras sube el nivel y las letras caen más rápido.
  • Pierdes cuando una columna se llena hasta arriba.
  • En computadora: flechas ← → para mover, ↓ o espacio para soltar, P para pausa.
